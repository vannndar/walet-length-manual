# Deteksi Penggaris

Tool ini dipakai untuk mengukur panjang burung dari gambar dengan kalibrasi manual pada penggaris.
Penandaannya memakai titik awal dan akhir, dengan garis bantu di ujung-ujung yang tegak lurus terhadap garis ukur.

## Cara pakai

1. Buka [index.html](/d:/Cool%20Yeah/Project/walet-length/deteksi-penggaris/index.html).
2. Jika perlu, klik `Load image` untuk memilih gambar lain atau `Pakai contoh folder`.
3. Tandai titik `0` pada penggaris.
4. Tandai titik `10` pada penggaris.
5. Tandai `Awal burung`.
6. Lihat garis bantu tegak lurus di ujung titik awal, lalu tandai `Akhir burung`.
7. Hasil panjang burung akan muncul otomatis dalam `cm`.

## Catatan

- Nilai `10` bisa diubah kalau mau memakai jarak referensi lain.
- Titik yang sudah dibuat bisa digeser ulang dengan drag.
- Di ujung garis pengukuran burung dan penggaris akan muncul cap garis tegak lurus terhadap garis dari titik A ke B.
- Area preview tidak lagi memakai scroll untuk zoom.
- Gunakan tombol `Zoom +`, `Zoom -`, atau `Fit image` di panel kiri untuk mengatur pembesaran.
- Gunakan `Ctrl + drag` pada preview untuk menggeser gambar.
- Pilih mode `Tidak memilih` bila ingin melihat gambar tanpa menambah titik.
- Panel `Pengaturan Keterangan` dipakai untuk menyalakan atau mematikan label titik, label jarak, dan garis bantu.
